## Question

Which selected repositories and GitHub operations belong in the first release and later extensions? Separate reading, issues/comments, contents/branches, PR creation, merge, Actions and settings, including the sandbox needed for code execution.

## Recommended direction — not a resolved decision

A selected-repository GitHub App with minimum permissions, read-first workflows and exact action previews; add writes by use case, with merge/Actions/admin denied unless deliberately enabled.

## Resolution evidence

A capability/approval matrix and first useful GitHub workflow, with test fixtures and repository/account boundaries.

## Comments

Charted, not worked. Claim before investigation. Human-in-the-loop decisions require the user's response; do not answer on their behalf.
