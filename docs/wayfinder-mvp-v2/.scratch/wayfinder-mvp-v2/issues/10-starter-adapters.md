## Question

Which Calendar/GitHub/local-workspace capabilities are required for the first release, and how do Notion/mail/WhatsApp Business/fitness adapters join later? Decide account onboarding, protected write scope and an honest support matrix.

## Proposed direction — not a resolved decision

Tavily plus approved documents are core; start Calendar/GitHub read-first and add exact writes separately. Every new provider passes configuration, scope, revoke, duplicate and recovery tests; general extensibility is not universal immediate API access.

## Comments
