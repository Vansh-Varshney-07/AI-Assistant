Architecture & Memory Specs

Notion ID: not_98242a-99 | Synced to FalkorDB space: primary_core

The Wayfinder AI desktop assistant utilizes a three-tier context and memory system:

  • Tier 1: Hot Context — In-memory session buffers, agent instructions, and scope contracts.
  • Tier 2: Context Cards — Evidence-backed task cards selected within a bounded token budget.
  • Tier 3: Durable Evidence — FalkorDB knowledge graph (entities, claims, relations) + embedded Qdrant vectors for high-precision retrieval.

All writes must pass through the Receipt Journal with SQLite state tracking and compensation rollback guarantees.
